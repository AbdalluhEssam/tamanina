# Adhan Audio Files

Place adhan audio files (.mp3) in this directory:

## Expected Files:
- `adhan_makkah.mp3` - أذان الحرم المكي (Sheikh Ali Mulla)
- `adhan_madinah.mp3` - أذان الحرم المدني (Sheikh Majeed Al-Abbasi)
- `adhan_fajr.mp3` - أذان الفجر (Special Fajr adhan)
- `adhan_default.mp3` - الأذان الافتراضي

## Audio Format Requirements:
- Format: MP3
- Sample Rate: 44.1kHz
- Bit Rate: 128kbps or higher
- Channels: Stereo or Mono

## License:
Make sure you have proper licensing rights for any adhan recordings used.

## Note:
The app will use system notification sound as fallback if these files are not present.
